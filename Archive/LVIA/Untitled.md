## 二、总体规律

### 1. `nkw` 越大，准确率越低

这是所有实验中最稳定的规律。

原因是：

> `nkw` 表示攻击目标关键词数量。关键词越多，候选空间越大，攻击者越难正确匹配查询和真实关键词。

例如第八组 threshold 正式实验中：

| 数据集     | nkw=500 最高准确率 | nkw=3000 最高准确率 |
| ---------- | ------------------ | ------------------- |
| enron-full | 0.3262             | 0.1289              |
| lucene     | 0.3525             | 0.1816              |

------

### 2. 时间划分越细，通常越有利，但不是绝对

`n_month` 越小，`# intervals` 越多。

| n_month | intervals |
| ------- | --------- |
| 18      | 1         |
| 6       | 3         |
| 3       | 6         |
| 2       | 9         |
| 1       | 18        |

一般来说，区间越多，LVIA 能获得更丰富的时间访问模式，因此准确率会提高。

但不同数据集最优点不同：

| 数据集     | 常见最佳时间划分          |
| ---------- | ------------------------- |
| enron-full | `n_month=2`，即 9 个区间  |
| lucene     | `n_month=1`，即 18 个区间 |

所以可以总结为：

> 时间划分太粗时信息不足；划分太细时可能引入稀疏性和噪声。Enron 更适合中等粒度，Lucene 更适合细粒度。

------

### 3. `alpha` 越大，准确率越高

第三、第四组实验都说明：

> 攻击者掌握的辅助信息越多，LVIA 查询恢复效果越好。

例如第三组中 `lucene, nkw=500, n_month=1`：

| alpha | accuracy |
| ----- | -------- |
| 0.4   | 0.3090   |
| 0.3   | 0.2319   |
| 0.2   | 0.1319   |
| 0.1   | 0.0595   |

第四组更极端，`alpha` 从 0.4 降到 0.3 后，准确率直接大幅下降，说明该实验设置下 LVIA 对辅助信息非常敏感。

------

### 4. threshold 不是越大越好，也不是越小越好

第八组正式 threshold 实验说明：

| 数据集     | 最优 threshold 特点            |
| ---------- | ------------------------------ |
| enron-full | 更偏中间值，如 0.2、0.25、0.35 |
| lucene     | 更偏较大值，如 0.4             |

原因可以理解为：

> threshold 太高会限制候选匹配，可能漏掉正确答案；threshold 太低会放入太多噪声候选，也会降低准确率。

------

### 5. known 条件下准确率极高

第五、第七组明显属于 known 条件实验。

它们和普通实验差异很大：

| 实验类型             | 准确率范围       |
| -------------------- | ---------------- |
| 普通 LVIA            | 通常 0.01 ~ 0.45 |
| alpha/threshold 实验 | 通常 0.01 ~ 0.35 |
| known 实验           | 多数 0.90 ~ 1.00 |

这说明：

> 当攻击者掌握充分已知信息时，LVIA 可以非常准确地利用关键词时间分布特征完成查询恢复。
